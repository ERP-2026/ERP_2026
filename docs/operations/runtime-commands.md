# 런타임 명령

ERP_2026은 현재 Repository Bootstrap 단계입니다. ROS1 패키지, launch 구성, 실행 스크립트 및 차량 통신 구현이 없으므로 **검증된 런타임 실행 명령이 없습니다**. 실행 가능 여부가 확인되기 전까지 ERP_2024 명령을 ERP_2026 명령으로 간주하지 않습니다.

## 향후 기록할 절차

각 절차를 구현·검증한 뒤 실제 명령, 실행 전 조건, 설정 파일, 확인 방법과 종료 방법을 기록합니다.

| 대상 | 상태 |
| --- | --- |
| LiDAR | TODO: 드라이버와 데이터 확인 절차 |
| Camera | TODO: 드라이버와 영상 확인 절차 |
| GNSS / IMU | TODO: 장치 연결과 상태 확인 절차 |
| Vehicle Interface | TODO: 차량 연결, 안전 조건 및 명령 확인 절차 |
| 전체 자율주차 흐름 | TODO: 통합 실행·검증 절차 |

차량 연결과 구동 관련 명령은 실제 장비와 안전 조건을 확인한 뒤에만 추가합니다.
